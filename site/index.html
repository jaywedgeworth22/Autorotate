Secret Rotation That Never Persists Plaintext

Autorotate is a multi-platform, zero-plaintext secret-rotation lifecycle engine: a web control center plus native iOS, macOS, and Android companion apps that keep credentials fresh across Infisical, files, the Apple Keychain, the Android Keystore, and generic HTTPS webhooks.  Secret material exists only in memory during a rotation and is never written to disk, logs, or the database unencrypted.

How A Rotation Works

Every rotation runs the same strict state machine, in order.

  1. Lock Acquire a per-secret lock so no other run starts while one is already in progress.
  2. Rotate The connector produces a new value for the credential.
  3. Push The new value is written to every enabled target — Infisical, a file, the Apple Keychain, the Android Keystore, or a webhook.
  4. Verify An optional read-back confirms the new value landed correctly.
  5. Commit Once every required target succeeds, the secret record updates to the new version.
  6. Audit A hash-chained record is appended, so the rotation history stays tamper-evident.

Any failure aborts and rolls back before new material is committed.

What It Rotates

Autorotate keeps credentials fresh across five kinds of targets.

  • Infisical projects
  • Local and remote files
  • Apple Keychain
  • Android Keystore
  • Generic HTTPS webhooks

Zero Plaintext

Secret material exists only in memory for the duration of a rotation run — it is never written to disk, logs, or the database unencrypted.  Every run also appends a hash-chained audit record, so the rotation history is tamper-evident.
